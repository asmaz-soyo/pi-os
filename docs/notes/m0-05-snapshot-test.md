# M0-05 UART 出力のスナップショットテスト

## 何をしたか

- `cargo xtask test --snapshot` を足した。各 BSP のカーネルをビルドして QEMU で起動し、シリアルの出力を `tests/snapshots/<bsp>.txt` と比べる
- `cargo xtask run [--bsp <bsp>]` を実装した(ビルドして QEMU で起動する)
- xtask の計画を「コマンド」だけでなく「スナップショットの比較」も表せる `Step` の列に変えた
- M1 の最初のテストとして、`tests/snapshots/qemu-virt.txt` に「Hello」を期待する出力を書いた。**このコミットの時点では、カーネルが何も出力しないので失敗する(Red)**。M1 の最初のステップで通す

## なぜ必要か

- 起動処理は単体テストが難しい。「起動したらこう表示される」を丸ごと期待値として持つのが一番素直
- 出力が変わったときは差分(最初に食い違った行)で分かる。意図した変更なら `UPDATE_SNAPSHOTS=1 cargo xtask test --snapshot` で期待値を更新し、その差分もレビューする

## 中で何が起きているか

- `-nographic` を付けると、QEMU は最初のシリアルポート(`virt` では PL011)を標準入出力につなぐ。xtask はその標準出力を取り込む
- カーネルは表示が終わったらセミホスティングで QEMU を終了させる。固まったときのために `timeout 30` で包む
- 比べる前に `\r` を消し、末尾の空行をそろえる(シリアルでは改行を `\r\n` で送るため)
