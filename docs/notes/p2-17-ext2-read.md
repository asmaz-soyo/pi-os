# フェーズ2-17 ext2 の読み込み

## 何をしたか

- `kernel::fs::ext2::Ext2`:ext2 を読み出し専用で読む `FileSystem`
  - スーパーブロック(バイト 1024 から)とグループ記述子の表を読む
  - inode(種類、大きさ、所有者、データブロックの場所)を番号で引く
  - 直接 12 個 + 1 段 / 2 段 / 3 段の間接ブロックをたどって中身を読む(穴は 0 で埋める)
  - ディレクトリの項目(inode 番号、項目の長さ、名前の長さ、名前)を読んでパスを解決する
- ホストのテストでは、テストの中で `mke2fs -d`(e2fsprogs)を使ってイメージを作り、RAM ディスクに載せて読む

## なぜ必要か

計画書:SD カードの p2 を ext2 にして `/` にする。シンボリックリンクとパーミッションが要るため(uv や npm が使う)。VFS と ext2 は学習のために自作する。

## 中で何が起きているか

### ブロックの場所の求め方(ブロック 1KiB、1 つの間接ブロックに番号 256 個)

| ファイルの中のブロック番号 | 場所 |
| --- | --- |
| 0〜11 | inode の `i_block[0..12]`(直接) |
| 12〜267 | `i_block[12]` の間接ブロックの中 |
| 268〜65803 | `i_block[13]` → 間接ブロック → その中 |
| それ以降 | `i_block[14]` で 3 段 |

### パスの解決

`/etc/conf/a` なら、ルート(inode 2)のディレクトリの項目から `etc` の inode 番号を探し、その中から `conf`、さらに `a` を探す。ディレクトリの中身は「inode 番号(4)、項目の長さ(2)、名前の長さ(1)、種類(1)、名前」の並び。
