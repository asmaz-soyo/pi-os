# M1-01 PL011 UART で「Hello」

## 何をしたか

- `hal::mmio`:レジスタの読み書きを表す `Mmio` トレイトと、実機用の `MmioRegion`(volatile アクセス)
- `hal::mock::FakeMmio`:書き込みを記録し、読み出しには予約した値を返すテスト用の偽物
- `drivers/pl011`:PL011 UART のドライバ。`Console` を実装する
- `kernel`:カーネルのコア(最初の中身)。`println!`、出力先の登録、起動メッセージ、`kmain`
- `bsp-qemu-virt`:PL011(`0x0900_0000`)をつくって初期化し、カーネルに出力先として登録する配線
- M0 で書いた「Hello」のスナップショットテストが通った(Green)

```
$ cargo xtask run
Pi-OS booting on qemu-virt
Hello from Pi-OS
```

## なぜ必要か

- UART はカーネルの「声」。以降のデバッグもテストも、まずここに文字が出ることが前提になる
- ドライバを `Mmio` トレイト越しに書くと、ホストの `cargo test` でレジスタへの書き込み順まで検証できる。実機がなくても「データシートどおりに初期化しているか」をテストで固定できる

## 中で何が起きているか

### PL011 の初期化(`Pl011::init`)

1. `CR = 0`:UART を止める(設定中に半端な状態で動かないように)
2. `ICR = 0x7ff`:保留中の割り込みをすべてクリア
3. `IBRD` / `FBRD`:ボーレートの分周比。`クロック / (16 × ボーレート)` の整数部と、小数部を 1/64 単位にしたもの。48MHz・115200bps なら 26 と 3
4. `LCR_H`:8 ビット、パリティなし、ストップビット 1(8N1)、FIFO を使う。ここに書いたときに分周比が反映される
5. `CR`:UART を有効にし、送信と受信を許可する

### 1文字の送信(`put`)

- `FR`(フラグレジスタ)の `TXFF`(送信 FIFO が満杯)が 0 になるまで待ってから、`DR` に書く
- シリアル端末は改行を `\r\n` で受け取るので、`\n` の前に `\r` を送る

### 出力先の登録

- `static UART: SpinLock<Pl011<MmioRegion>>` を BSP が持ち、`kernel::console::set_console(&UART)` で登録する
- `println!` はロックを取ってから書くので、複数のコアが同時に書いても行が混ざらない
- `spin::Once` で「1回だけ登録」を保証している

## 注意(後で直すこと)

- MMU がオフの間、メモリはすべて Device 属性として扱われる。実機の Cortex-A53 では、Device メモリ上の排他ロード/ストア(スピンロックが使う `ldaxr`/`stlxr`)が期待どおり動かないことがある。QEMU では動く。M3 で MMU を有効にして、RAM を Normal 属性にすれば解消する
- パニック中にロックを持ったままだと、パニックの表示で固まる。パニック処理で対処する(次のステップ)
