# フェーズ2-35 VFS:ext2 のシンボリックリンク

## 何をしたか

- 読む:inode の種類 `0xA000`(`S_IFLNK`)を `FileKind::Symlink` にし、`readlink` で指す先を返す
  - 短いリンク(60 バイト未満、データブロックなし):指す先の文字列が、inode のブロック番号の欄(`i_block`、4 バイト × 15 = 60 バイト)にそのまま入っている(fast symlink)
  - 長いリンク:普通のファイルと同じくデータブロックに入っている
- 作る:`Ext2::symlink`。短ければ `i_block` に、長ければデータブロックに書く。ディレクトリの項目の種類は 7(シンボリックリンク)
- 消す:短いリンクの `i_block` は文字列なので、ブロックとして返す前に 0 にする(しないと、文字列のバイトをブロック番号と思って、他人のブロックを空きにしてしまう)
- `add_entry` は種類(`FileKind`)を受け取るようにした(rename でリンクを動かしたときも種類が正しく残る)
- テスト:`mke2fs -d` が作った短いリンクと長いリンクを読む。作って、再マウントして読み戻し、消して、`e2fsck -fn` できれいなことを確かめる
