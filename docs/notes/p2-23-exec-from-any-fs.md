# フェーズ2-23 どのファイルシステムのプログラムも実行できるように

## 何をしたか

- `kernel::exec::read_image(file)`:実行ファイルの中身を返す。initramfs のファイルはメモリの中をそのまま指し(`Cow::Borrowed`)、それ以外(tmpfs、ext2、FAT32)は `read` で全部読んで持つ(`Cow::Owned`)
- `execve`、カーネルが最初のプロセスを起こす `spawn_program`、`/etc/init.rc` を読む `read_file` がこれを使う
- テスト:initramfs のプログラムを tmpfs に写し(モード 0755)、そこから `execve` できる

## なぜ必要か

これまでは「中身を直接見せる」initramfs のファイルしか実行できなかった(`File::contents`)。ルート(`/`)を ext2 にするには、ディスクのファイルを実行できる必要がある。

## まだのこと

- 実行ファイルを丸ごと読んでから読み込んでいる。大きなプログラム(qjs は約 1MB)では、ページが要るときに読む(デマンドページング)ほうが速く、メモリも少なくて済む
