# フェーズ2-55 VFS:O_APPEND(不具合の修正)

## 何をしたか

- `O_APPEND`(追記)で開いたファイルに書くと、ファイルの終わりではなく今の位置(開いた直後なら先頭)に上書きしていた。シェルの `echo x >> file` やログの追記が壊れる
- `OpenFile::append`:追記の印。書くたびに、書く直前のファイルの大きさを位置にする(`lseek` で戻しても、ほかの fd が途中で伸ばしても、終わりに書く)
- `fcntl(F_SETFL)` で O_APPEND を付けたり外したりできる。`F_GETFL` は今の印を返す
- テスト:tmpfs でのシステムコール、互換テスト(Linux と一致)

## どう見つけたか

VFS の現状をまとめるために、実装済みのシステムコールとフラグを見直していて気づいた。O_APPEND を見ているところが 1 か所もなかった
