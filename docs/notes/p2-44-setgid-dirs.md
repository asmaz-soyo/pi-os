# フェーズ2-44 VFS:setgid のディレクトリ

## 何をしたか

- 親ディレクトリに setgid(`S_ISGID` = 0o2000)があれば、中に作ったファイル・ディレクトリ・リンクのグループを、作った人のグループではなく親ディレクトリのグループにする
- 中に作ったディレクトリは setgid のビットも受け継ぐ(孫も同じグループになる)
- テスト:グループ 50 の 2777 のディレクトリに、グループ 100 のユーザーが作ったものがグループ 50 になる

## なぜ必要か

チームの共有ディレクトリ(`chgrp team dir; chmod 2775 dir`)の定番。誰が作っても同じグループの持ち物になるので、グループのメンバー全員が読み書きできる。
