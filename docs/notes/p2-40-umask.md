# フェーズ2-40 VFS:umask

## 何をしたか

- `Process::umask`(既定 0o022)。fork した子に受け継がれ、exec しても変わらない
- `umask`(166):新しい値(下の 9 ビットだけ)を設定し、前の値を返す
- `openat(O_CREAT)` と `mkdirat` は、指定された mode から umask のビットを消してから作る(`mode & !umask`)

```
umask 022:open(..., O_CREAT, 0666) → 0644、mkdir(..., 0777) → 0755
umask 077:自分だけが読み書きできるファイルになる
```

## なぜ必要か

プログラムはふつう「最大限開いた」mode(ファイルは 0666、ディレクトリは 0777)で作り、実際にどこまで開くかはユーザーが umask で決める。これがないと、一般ユーザーが作ったファイルを誰でも書き換えられてしまう。
