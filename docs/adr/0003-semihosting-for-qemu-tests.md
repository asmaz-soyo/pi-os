# ADR-0003: QEMU の結合テストの終了と出力にセミホスティングを使う

- 状態:採用
- 日付:2026-11-20

## 背景

QEMU 上のカーネル内テストの結果を、CI が自動で判定できる形で返したい。テストの仕組みは UART ドライバより先に必要だった。

## 決定

QEMU を `-semihosting` 付きで起動し、`SYS_EXIT` で終了コード(成功 0、失敗 1)を返す。テストの出力も、UART ができるまでは `SYS_WRITEC` で出す。

## 理由

- `-M virt` と `-M raspi3b` の両方で同じ方法が使える(`isa-debug-exit` のような x86 専用の仕組みに頼らない)
- UART ドライバがなくても文字を出せる

## 影響

- 実機にはセミホスティングがないので、テストとデバッグ専用。通常の出力は UART を使う
- 実機でのテストは、将来 UART の出力を検証する方式(ハードウェア・イン・ザ・ループ)で行う
