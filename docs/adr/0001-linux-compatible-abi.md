# ADR-0001: Linux 互換のシステムコール ABI を採用する

- 状態:採用
- 日付:2026-11-20

## 背景

フェーズ1のゴールは QuickJS(`qjs`)を動かすこと。その先には Python や BusyBox、Node.js も動かしたい。これらを自作 OS 用に移植するのは大きな作業になる。

## 決定

Linux AArch64 のシステムコール番号と呼び出し規約(`svc #0`、番号は `x8`、引数は `x0`〜`x5`、戻り値は `x0`、エラーは負の errno)をそのまま採用する。ユーザー空間のプログラムは musl で静的リンクし、無改造で動かす。

## 理由

- musl と zig cc / Rust の `aarch64-unknown-linux-musl` で、既存のプログラムをそのまま使える
- 必要なシステムコールだけを順に実装すればよく、未実装のものは `ENOSYS` を返してログに残せば、次に何を作るべきかが分かる
- 同じバイナリを Linux(`qemu-aarch64`)でも動かせるので、結果を比べる互換テストが作れる
- 独自 ABI だと、libc の移植から始める必要がある

## 影響

- Linux の仕様(errno、構造体のレイアウト、`auxv` など)に合わせる必要がある
- 互換層は「駆動する側のアダプター」の1つとして作り、独自 ABI や WASI を後から並べられる形にする
