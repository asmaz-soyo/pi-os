# M1 起動とUART

## 目的

raspi3 と qemu-virt の両方の BSP で起動し、UART に「Hello」を出す。パニックしたときにレジスタとスタックトレースを出す。

## 完了条件

- [x] PL011 ドライバ(ホストのテストでレジスタ操作を検証)
- [x] qemu-virt で「Hello」(スナップショットテスト)
- [x] raspi3 で「Hello」(QEMU `-M raspi3b`、スナップショットテスト)
- [x] EL3 / EL2 から EL1 への降下
- [x] パニック時のレジスタとスタックトレース(スナップショットテスト)
- [ ] 実機の Pi 3B での確認(手動。未実施)

## 学んだこと

- 起動方法によって始まる例外レベルが違う(QEMU raspi3b の ELF は EL3、実機は EL2、virt は EL1)
- フレームポインタを有効にすると、スタックを連結リストとしてたどれる
- 詳しくは `docs/notes/m1-*.md`
